# App 操作截圖

2026-09-10 以 Android 模擬器上的原生開發版 App 實際操作擷取，解析度為 1080 × 2400。程式碼版本為 `7a1436c`；圖片未修改。

| 截圖 | 操作與結果 |
| --- | --- |
| [01-demo-setup.png](01-demo-setup.png) | 設定頁：英文、功能開啟、一次載入、3 位專家、正常情境。 |
| [02-consultation-en.png](02-consultation-en.png) | 點擊 Premium Consultation，進入英文諮詢頁。 |
| [03-sheet-expanded.png](03-sheet-expanded.png) | 向上拖曳底部面板，顯示三位專家及熱線；服務時間與操作按鈕維持固定。 |
| [04-consultation-zh.png](04-consultation-zh.png) | 返回設定，切換繁體中文後重新進入諮詢頁。 |

| [06-next-page-error.png](06-next-page-error.png) | 選擇無限捲動、120 位專家、下一頁失敗；捲動觸發錯誤後，第 10–12 筆既有資料仍顯示，並提供重試按鈕。 |
